## Profile

I work at the intersection of **engineering, design, and public-sector data** — building analytics platforms and decision-support tools for government stakeholders. My focus is making complex civic and administrative data legible: fast, compact, high-density interfaces that help policymakers decide, not just observe.

Currently a **Young Professional in the Data vertical** at a government technology organization, working on dashboard architecture, data visualization pipelines, and decision-intelligence systems for public administration.

## Design Philosophy

<table>
<tr><td>

- Performance first — clutter is a cost, not a feature
- Compact, high information-density interfaces over decorative ones
- Interfaces should help people decide faster, not admire longer
- Government software should feel as considered as consumer software
- Usability outranks visual polish, but the two aren't in conflict

</td></tr>
